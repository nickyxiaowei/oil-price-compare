# 油价对比计算器

在线地址：https://nickyxiaowei.github.io/oil-price-compare/

单文件网页工具，输入一次加油需求，横向比对各加油渠道的真实实付、平均单价和每升节省。电脑双击 `index.html` 即可使用，手机直接开上面的链接，无需联网后端、无依赖。

## 内置渠道

| 渠道 | 优惠方式 | 公式 |
| --- | --- | --- |
| 平安好车主 | 立减金额 | 升数 = 金额 ÷ 原价；实付 = 金额 − 优惠金额 |
| 小景美孚 | 每升优惠 + 服务费 | 毛优惠 = 升数 × 每升优惠；服务费 = max(最低服务费, 毛优惠 × 费率)；实付 = 金额 − (毛优惠 − 服务费) |

两个渠道最终都换算成同一个可比指标：**平均单价 = 实付 ÷ 升数**。

## 功能

- 顶部统一填汽油原价、加油金额，结论条直接给出最低单价渠道与实付差额
- 每张渠道卡可切换「立减金额 / 每升优惠」两种模式，并单独设置服务费率、最低服务费
- 每个渠道可填独立加油金额，留空则跟随顶部总金额（适合各渠道档位不同的情况）
- 每张卡附完整计算过程，数字可逐行核对
- 可添加自定义渠道，参数保存在本机浏览器 localStorage，不上传

## 精度说明

升数按「金额 ÷ 单价」四舍五入到 0.01 L 计算，用于估算，与油机实际显示可能相差几分钱。服务费、实付均按分四舍五入。
